วิธีติดตั้ง

แอปยังไม่ได้ลงทะเบียนกับ Apple/Microsoft/Google Play ครั้งแรกจึงมีคำเตือน ทำตามนี้ได้เลย

  1. ดาวน์โหลด Apple ชิป (M1–M4) หรือ Mac Intel ให้ตรงเครื่องเช็กที่เมนู Apple → About This Mac — ถ้าโหลดผิดตัว แอปจะช้ามาก
  2. ดับเบิลคลิกไฟล์ zip แล้วลาก Price Tracker ไปไว้ใน Applications
  3. เปิดครั้งแรก: คลิกขวา → Open → Openถ้าขึ้น "ไม่สามารถตรวจสอบผู้พัฒนาได้": System Settings → Privacy & Security → เลื่อนลง → Open Anyway
  4. ยังเปิดไม่ได้? เปิด Terminal แล้ววาง: xattr -cr "/Applications/Price Tracker.app"
  5. อัปเดต: โหลด zip ใหม่แล้วลากทับของเดิม — การตั้งค่าและ watchlist ยังอยู่
  1. ตัวติดตั้ง: ดับเบิลคลิก Price-Tracker-Setup-….exe → เลือกโฟลเดอร์ → Installมี shortcut ที่ Desktop และ Start menu
  2. ถ้าขึ้น Windows protected your PC (SmartScreen): กด More info → Run anyway
  3. Portable: วาง Price-Tracker-portable-….exe ไว้ที่ไหนก็ได้ (เช่น USB) แล้วดับเบิลคลิกการตั้งค่าเก็บในโฟลเดอร์ "Price Tracker Data" ข้างไฟล์
  4. Zip: แตกไฟล์แล้วเปิด Price Tracker.exe · สร้างโฟลเดอร์ "Price Tracker Data" ข้างไฟล์ถ้าอยากให้เป็นแบบ portable
  5. ปิดหน้าต่างแล้วแอปยังทำงานที่ System tray (ข้างนาฬิกา) — คลิกไอคอนเพื่อเปิดกลับ
  1. เปิดหน้านี้บนมือถือ แล้วกด ดาวน์โหลด APK
  2. แตะไฟล์ที่โหลด → ถ้าขึ้น "ไม่อนุญาตให้ติดตั้งจากแหล่งนี้" แตะ การตั้งค่า → อนุญาตจากแหล่งนี้ → กลับมาแตะ ติดตั้ง
  3. ถ้า Play Protect เตือน แตะ รายละเอียดเพิ่มเติม → ติดตั้งต่อไป
  4. เปิดแอป → เลือก Demo หรือ เข้าสู่ระบบ VCG ด้วยอีเมล + รหัสผ่าน (ปุ่ม Google ใช้ในแอปไม่ได้)
  5. อัปเดต: ติดตั้ง APK ใหม่ทับได้เลย ไม่ต้องลบของเดิม
  1. เปิด เว็บแอป ใน Chrome, Edge หรือ Safari
  2. คอม / Android: กดปุ่ม ติดตั้งเป็นแอป มุมซ้ายล่าง (หรือไอคอนติดตั้งในแถบที่อยู่) → Install
  3. iPhone / iPad: Safari → ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม
  4. เปิดจากไอคอนบนหน้าจอได้เหมือนแอปทั่วไป ใช้งานออฟไลน์ได้ (ยกเว้นราคาและข่าว)
    5. เว็บแอปใช้ราคา Demo ฝึก บทเรียน เครื่องคำนวณ MM และแดชบอร์ดได้ — ราคาจริงจาก VCG/MT5 ต้องใช้แอป Mac, Windows หรือ Android

เชื่อมต่อ MT5 (Mac / Windows)

ใช้ได้ทุกโบรกเกอร์ที่มี MT5 — แอปอ่านราคา (และออเดอร์ของคุณ) จาก MT5 ในเครื่อง ไม่ส่งคำสั่งซื้อขาย

  1. ติดตั้ง MetaTrader 5 แล้วเปิด 1 ครั้ง
  2. ใน MT5: File → Login to Trade Account → เลขบัญชี + รหัสผ่าน + Server ของโบรกเกอร์ใช้ "รหัสผ่านนักลงทุน (investor password)" ได้ — ดูราคาได้ ส่งออเดอร์ไม่ได้
  3. Tools → Options → Expert Advisors → ติ๊ก Allow WebRequest for listed URL → เพิ่ม http://127.0.0.1
  4. ปิด MT5 แล้วในแอป Price Tracker: คู่มือเริ่มต้น → MT5 → เปิด MT5 พร้อม EAแอปจะคัดลอก EA, compile และเปิด MT5 พร้อม EA บนกราฟให้
  5. เห็น "เชื่อมต่อแล้ว: ชื่อโบรกเกอร์" ในแอป = เสร็จ · ครั้งต่อไปแอปจะเปิด MT5 ให้เองแบบย่อหน้าต่าง

คำถามที่พบบ่อย

แอปนี้ส่งคำสั่งซื้อขายได้ไหม

ไม่ได้ แอปอ่านราคาและแสดงผลเท่านั้น EA ใน MT5 ก็อ่านอย่างเดียว ไม่มีคำสั่งเปิด/แก้/ปิดออเดอร์ ส่วน "ฝึกเทรด" ในแอปใช้เงินสมมติทั้งหมด

รหัสผ่านปลอดภัยไหม

รหัสผ่าน VCG กรอกในหน้าเว็บของ VCG เอง และรหัส MT5 กรอกในโปรแกรม MT5 — แอปไม่เห็นและไม่เก็บรหัสผ่าน
